================================================================================
DIGITAL STUDENT GRIEVANCE & FEEDBACK PORTAL - HOW TO START AND RUN
================================================================================

This guide explains how to set up the database and start the portal on your machine.


--------------------------------------------------------------------------------
PREREQUISITES ALREADY INSTALLED ON YOUR SYSTEM
--------------------------------------------------------------------------------
1. Java 17: Installed at:
   C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot

2. Apache Tomcat 10.1: Extracted at:
   C:\Users\ushaa\.gemini\antigravity\scratch\tools\apache-tomcat-10.1.20

3. Apache Maven 3.9: Extracted at:
   C:\Users\ushaa\.gemini\antigravity\scratch\tools\apache-maven-3.9.6

4. Pre-built WAR file: Already compiled and ready at:
   C:\Users\ushaa\.gemini\antigravity\scratch\student-grievance-portal\target\student-grievance-portal.war


--------------------------------------------------------------------------------
STEP 1: INITIALIZE THE MYSQL DATABASE
--------------------------------------------------------------------------------
Make sure your MySQL service is running (e.g. standard MySQL or XAMPP MySQL).

Option A: Using MySQL Command Line
Open a terminal / command prompt and run:
  mysql -u root -p < "C:\Users\ushaa\.gemini\antigravity\scratch\student-grievance-portal\sql\schema.sql"
  mysql -u root -p < "C:\Users\ushaa\.gemini\antigravity\scratch\student-grievance-portal\sql\sample_data.sql"

Option B: Using MySQL Workbench or phpMyAdmin
1. Open MySQL Workbench or phpMyAdmin.
2. Open and run the file:
   student-grievance-portal/sql/schema.sql
3. Open and run the file:
   student-grievance-portal/sql/sample_data.sql

This creates the database "student_grievance_portal" and loads all tables and sample data.


--------------------------------------------------------------------------------
STEP 2: CONFIGURE DATABASE PASSWORD
--------------------------------------------------------------------------------
Open the file:
  student-grievance-portal/src/main/resources/db.properties

Check the username and password:
  db.url=jdbc:mysql://localhost:3306/student_grievance_portal?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC&characterEncoding=UTF-8
  db.username=root
  db.password=root

* If your MySQL password is empty (like default XAMPP), set:
  db.password=
* If you changed db.properties, rebuild the WAR by running in the project directory:
  mvn clean package (or use the existing one if root/root or default matches)


--------------------------------------------------------------------------------
STEP 3: START THE SERVER (1-CLICK)
--------------------------------------------------------------------------------
Navigate to the project folder:
  C:\Users\ushaa\.gemini\antigravity\scratch\student-grievance-portal

Double-click:
  start.bat

What this script does:
1. Sets JAVA_HOME to Java 17.
2. Builds the WAR if needed using Maven Wrapper.
3. Copies the WAR file into Tomcat's webapps directory.
4. Launches Apache Tomcat.
5. Automatically opens your web browser to:
   http://localhost:8080/student-grievance-portal/


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
STEP 5: STOP THE SERVER
--------------------------------------------------------------------------------
When you are done with your demonstration or testing:
Double-click:
  stop.bat

This cleanly shuts down Apache Tomcat and frees port 8080.


--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------
1. "Port 8080 already in use":
   Run stop-portal.bat or open PowerShell and run:
   Get-Process java -ErrorAction SilentlyContinue | Stop-Process -Force

2. "Database connection error (HTTP 500)":
   Ensure MySQL service is started and verify password in db.properties.

3. "Need to rebuild WAR after changes":
   Open PowerShell and run:
   $env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot"
   $env:Path = "$env:JAVA_HOME\bin;C:\Users\ushaa\.gemini\antigravity\scratch\tools\apache-maven-3.9.6\bin;$env:Path"
   cd "C:\Users\ushaa\.gemini\antigravity\scratch\student-grievance-portal"
   mvn clean package -DskipTests
